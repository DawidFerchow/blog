**Junior Full-Stack Developer**

This was my first job as a programmer. The main technology stack I worked with was WordPress, together with Elementor or Gutenberg.

My work was mainly connected with changing the look or functionality of existing modules, or creating new modules when they were needed. Depending on the project, I used ready-made Elementor modules and styled them according to designs from Figma.

The situation was similar in projects where Gutenberg was the default page builder. An important requirement was to keep the possibility of editing these elements later in the WordPress panel.

I also worked on projects without classic page builders. In these projects, modules were created with ACF directly in PHP. For styling and adding functionality, I used JavaScript, jQuery and Sass.

Another part of my work was creating the adobeDataLayer object for Adobe integration. The script listened for clicks on links and functional buttons. Depending on the function and position of the clicked element, it prepared the correct information and added it to the object. The same process was also used when a user entered a page.

My position required working on several different projects, sometimes even during one day. Thanks to this, I learned how to work with different environments at the same time.

In this job, I learned the full workflow of working as a developer. I learned terms and processes such as DEV, STG and PRD environments, working on live projects, Git, GitHub, commits, code review, pull requests, merge, branches, Agile, Jira, estimations, PM, daily calls and sprints.

**Main responsibilities**

* Coding new functionalities in PHP for WordPress CMS through `functions.php`
* Creating elements such as single pages, archive pages, pop-ups, listings, dynamic modules, options pages, navigation, filters and pagination in WordPress, using Elementor and JetEngine plugins
* Styling Elementor widgets for specific projects, based on Figma designs, using Sass and the BEM methodology
* Adding, modifying and extending Elementor widget functionalities by writing new functions in JavaScript and jQuery, including creating and using custom events
* Creating the adobeDataLayer object for Adobe integration, according to guidelines from the Adobe specialist or the client
* Working with Git and GitHub: branches, commits, pull requests, merging and resolving conflicts
* Reporting to the Project Manager in Scrum and Agile methodology, using Jira, Teams and Confluence
* Communicating with the Design Team using Figma

**Technology stacks**

* WordPress with:

  * ACF, PHP, JavaScript and Sass: 2 projects
  * Elementor and JetEngine with:

    * JavaScript and Sass: 3 projects
    * JavaScript and Adobe integration: 2 projects
    * WooCommerce and PHP: 1 project
